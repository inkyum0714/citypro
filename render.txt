CityFlow — Render 배포 설정

Language
  Python 3

Build Command
  pip install -r requirements.txt

Start Command
  gunicorn wsgi:app --bind 0.0.0.0:$PORT --workers 1 --threads 8 --timeout 120

Health Check Path
  /health

필수 환경 변수
  SECRET_KEY                 세션 서명 키 (미설정 시 Render에서 재시작마다 로그아웃됨)
  PYTHON_VERSION             3.12.10  (runtime.txt / .python-version과 동일)

권장 환경 변수
  PUBLIC_BASE_URL            https://<서비스명>.onrender.com
  DATA_DIR                   Persistent Disk 마운트 경로 (예: /var/data)
  GOOGLE_ENABLED             true
  GOOGLE_CLIENT_ID           Google OAuth 클라이언트 ID
  GOOGLE_CLIENT_SECRET       Google OAuth 클라이언트 시크릿
  TOSS_CLIENT_KEY            토스페이먼츠 클라이언트 키 (위젯)
  TOSS_SECRET_KEY            토스페이먼츠 시크릿 키 (서버 승인, 절대 프론트에 넣지 말 것)
  REDDIT_COUPON_CODE         레딧 체험 쿠폰 8자리 (기본 RDT1WEEK, 선착순 10명)
  ADSENSE_CLIENT_ID          Google AdSense ca-pub-… (없으면 가족 안심 하우스 광고)
  ADSENSE_SLOT_ID            AdSense 상단 배너 슬롯 ID
  ADFIT_UNIT_ID              카카오 애드핏 유닛 ID (AdSense가 없을 때)

토스 정산(계좌 등록은 직접)
  1. https://www.tosspayments.com 에서 상점 가입
  2. 개발자센터에서 테스트/라이브 API 키 발급
  3. 상점관리자 > 정산 계좌에 토스뱅크(또는 원하는 계좌) 등록
  4. 위 키를 Render Environment에 넣고 재배포
  5. 결제 금액은 토스페이먼츠 수수료 차감 후 정산일에 등록 계좌로 입금됨
  개인 토스 송금 QR이 아니라 토스페이먼츠 정산입니다.

상단 광고
  - 무료 사용자만 화면 최상단에 배너가 보입니다. PRO는 광고가 꺼집니다.
  - 토스페이먼츠 키만 있으면 하우스 광고 클릭 → PRO 결제로 수익이 정산됩니다.
  - 노출(CPM) 수익은 Google AdSense 또는 카카오 애드핏 퍼블리셔 ID를 같은 방식으로 넣으면 됩니다.
  - 성인·선정성 광고는 하우스 인벤토리에서 제외합니다. AdSense/애드핏 콘솔에서도 Adult/성인 카테고리를 차단하세요.

참고
  - workers는 반드시 1 (시뮬레이션 상태가 프로세스 메모리에 있음)
  - threads는 WebSocket(flask-sock) 동시 연결용
  - pygame은 프로덕션 requirements.txt에 넣지 않음 (헤드리스 빌드 실패 방지)
  - Render는 디스크가 기본 휘발성이라 users.json / user_progress.json 유지에는 DATA_DIR + Disk 필요
  - TRUST_PROXY_HEADERS는 RENDER=true이면 자동 활성화됨
